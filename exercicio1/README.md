Dia 1 · Fundamentos: sua assinatura cabe no orçamento?
⏱️ 10–20 minutos · Objetivo: praticar variáveis, entrada de dados, cálculos e if/else.
Vamos começar com uma pequena funcionalidade de um gerenciador de assinaturas.
O conceito
input() recebe dados como texto. Para calcular com valores decimais, converta-os com float(). Uma condição if/else permite escolher a mensagem conforme o resultado de uma comparação.
Seu desafio
Crie um programa que:

1. Peça o nome de uma assinatura, seu valor mensal e o orçamento disponível.
2. Se o valor for menor ou igual ao orçamento, informe quanto sobra.
3. Caso contrário, informe quanto falta.
   Considere valores não negativos e entradas numéricas válidas. Digite decimais com ponto, como 29.90. Mostre os valores com duas casas decimais.

Exemplo de execução
Nome da assinatura: Música
Valor mensal: 29.90
Orçamento disponível: 50
Música cabe no orçamento. Sobra: R$ 20.10
